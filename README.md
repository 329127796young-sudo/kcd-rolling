# 墙洞酒馆 · Wallhole Tavern

一个无需构建工具的中世纪酒馆骰子博弈原型，按你提供的《天国拯救 2》规则页和实机截图重做，包含：

- 主界面：通过“寻找牌友”打开独立牌桌选择弹窗；支持免费练习桌和正式赌局，另有“我的骰盒”入口。
- 货币系统：统一使用格罗申；默认钱包 100 格罗申。练习桌不扣本金，胜利固定奖励 5 格罗申；正式赌局基础赌注为 10 / 50 / 100 / 300 格罗申，玩家获胜按最终公共牌桌倍率获得收益，玩家落败则按自己主动选择过的最高风险倍率扣款（未主动推过 x2 时封顶 x2）。
- 单机对战：六枚骰子、保留骰子、无限续掷、爆骰归零、热骰与 AI 回合；活动中的剩余骰子显示在牌面，已保留骰子在选择后仍留在原位，点击再次投掷时才会收起并从下一掷碰撞中移除。每次再掷独立计算当前掷的组合，不会把上一掷的三同与下一掷单骰拼接计分。
- 对手差异：米洛偏稳健，瓦茨拉夫偏冒险，玛蒂娜是会做一步收益前瞻的账房型对手（领先封锁分差、落后时低风险追分），穆萨偏概率判断；每位对手有不同收集阈值、骰子组合和获胜目标。米洛/瓦茨拉夫目标为 2000 分，玛蒂娜目标为 3000 分，穆萨目标为 4000 分。
- 规则组合：1 点、5 点、三同、四/五/六同翻倍、小顺、大顺。
- 骰子库：玩家默认装备六枚普通骰子；内置特殊骰子及 1–6 点概率，可点击装备并影响实际投掷权重，也可随时使用“还原普通骰”恢复默认配置。
- 名片商店：收藏页分组展示三张对手胜利奖励名片、八张风景名片与八张“油画 DLC”名片；两组付费名片均可用格罗申购买，购买/装备状态分别写入 `wallhole-collection-v1` 与 `wallhole-wallet-v1`，不影响胜率。
- 骰子皮肤：顶部“骰子”入口提供独立的外观皮肤收藏与装备页；首发“墙洞酒馆 · 黑橡木铜箍”定价 120 格罗申。皮肤状态写入 `wallhole-dice-skins-v1`，只改变 3D 材质，不影响功能骰子权重、计分或 AI；当前黑橡木纹理由本地 CanvasTexture 生成，“我的骰盒”改为管理六个功能骰子槽位。
- 规则页：通过牌桌右侧“查看规则”进入；骰子配置通过左侧“编辑组合”或主页“配置我的骰子”进入，包含基本规则、点数组合、骰子概率、保留/爆骰、获胜条件与牌桌提示。
- 联机入口：主页“联机演示”切换、房间编号与对手状态，方便后续接入 WebSocket。
- 牌桌界面：顶部仅保留“牌桌”状态入口；“返回主页”按钮固定在牌桌工具栏的高对比层级，不会被透明骰子画布遮挡。
- 默认棋盘：第一阶段使用 `assets/images/boards/tavern-oak/base.webp` 作为墙洞酒馆旧橡木桌面，并叠加独立的 `wear.png` 磨损层；中央骰子区保留透明 3D 画布，木桌材质位于其下方。
- 棋盘扩展：顶部“棋盘”入口已经接入主题选择菜单，当前启用旧橡木，贵族大厅与城堡宴席先作为锁定占位主题；后续可在 `BOARD_THEMES` 与 `assets/images/boards/` 下追加主题资源。主题通过 CSS 变量切换主体纹理、磨损层和强调色，不需要改动骰子物理逻辑。
- 场景背景：主页使用 `assets/images/homepage-bg-01-02.webp` 作为 `01.webp`（左）与 `02.webp`（右）拼接后的横向中世纪骰子插图背景；牌桌场景使用 `assets/images/tavern-bg.svg`。原始图片保留在 `assets/images/01.webp`、`assets/images/02.webp`，`assets/images/名片.webp` 作为后续功能素材归档。
- 图片资源统一放在 `assets/images/`，音频资源放在 `assets/audio/`，便于后续检索和按用途调用。
- 三维骰子层：牌桌中央只使用 Three.js r128 在透明 canvas 上渲染木制骰子本身，`renderer.setClearColor(0x000000, 0)` 保证 2D 牌桌背景直接透出。骰子投射到 `THREE.ShadowMaterial` 地板（`opacity: 0.4`）的实时 PCF 软接触阴影，不再绘制独立木盒模型。
- 物理投掷组件：`dice-physics.js` 使用 Cannon.js 在透明 canvas 上模拟骰子。每位玩家固定六个可复用实体，下一掷只激活未锁定槽位，不会无限堆积 Mesh；骰子从靠近骰盅的集中位置带共同前进方向散开，不再从整张桌面凭空随机生成。骰子在接近桌面、仍处于下降阶段时提前完成目标朝向插值，落地后不再突然改变点数姿态，同时仍使用预先计算的权重结果。锁定骰子在选择后保持可见，下一次投掷开始时才从牌面收起并暂时隐藏，同时移出碰撞，热骰或新回合时由同一实体池重新显示。重力为 `-25`，骰子材质使用摩擦力 `0.5`、弹性系数 `0.3`；静止判定为速度 `0.11`、角速度 `0.12` 持续 `0.2s`。四面不可见高墙和地板按照牌桌框尺寸动态测量，另有越界安全围栏防止高能量帧把骰子带出牌桌。碰撞冲量会触发骨质 Web Audio 撞击声和轻微镜头震动，翻滚/滑动阶段增加节流的低音量摩擦噪声。蜡烛光和补光阴影贴图提升至 `1024×1024`。可通过 `window.DicePhysics3D.rollDice(count, targetValues, callback, options)` 投掷，并使用 `onDiceSelected`、`onDragRoll` 接收 3D 交互回调。
- 三维交互：鼠标悬停骰子时显示金色材质微光并切换指针；点击任意 3D 骰子都可通过 `onDiceSelected(diceId, value)` 锁定或解锁，不再要求当前组合先产生分数。零分组合仍可继续投掷并保持 0 分，由玩家自行承担选择结果；拖拽释放会把方向脉冲传给未锁定骰子。牌桌不再渲染 2D 骰子镜像，骰子只存在于透明 Three.js Canvas。
- 投掷反馈：骰盅过渡动画、骰子翻滚动画、可见的对手回合和键位操作提示（E 保留、F 保留并投掷、Q 收集、R 重开、T 规则）。

## 运行

直接打开 `index.html` 即可体验。若希望通过本地 HTTP 服务运行：

```powershell
$python = 'C:\Users\boomhauer\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
Start-Process -WindowStyle Hidden -FilePath $python -ArgumentList '-m','http.server','4173' -WorkingDirectory 'O:\001'
```

然后访问 `http://127.0.0.1:4173/`。

当前项目是前端可玩的离线原型，联机模式使用本地状态机模拟匹配和对手回合，不会建立真实网络连接。Three.js 与 Cannon.js 通过 CDN 加载；若运行环境阻止 CDN，页面会自动隐藏 3D canvas 并保留牌桌 UI，但不会生成 2D 骰子替代层。要做到成品级 1:1 美术还需要替换酒馆背景、角色肖像与骰子材质资源。
