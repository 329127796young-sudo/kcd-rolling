# 墙洞酒馆 · Wallhole Tavern

一个无需构建工具的中世纪酒馆骰子博弈原型，按你提供的《天国拯救 2》规则页和实机截图重做，包含：

- 主界面：选择单机/联机演示、选择不同风格对手、进入牌桌和配置骰子。
- 单机对战：六枚骰子、保留骰子、无限续掷、爆骰归零、热骰与 AI 回合；活动中的剩余骰子显示在牌面，已保留骰子在选择后仍留在原位，点击再次投掷时才会收起并从下一掷碰撞中移除。每次再掷独立计算当前掷的组合，不会把上一掷的三同与下一掷单骰拼接计分。
- 对手差异：米洛偏稳健，瓦茨拉夫偏冒险，玛蒂娜偏防守；每位对手有不同收集阈值和骰子组合。
- 规则组合：1 点、5 点、三同、四/五/六同翻倍、小顺、大顺、三对。
- 骰子库：玩家默认装备六枚普通骰子；内置特殊骰子及 1–6 点概率，可点击装备并影响实际投掷权重，也可随时使用“还原普通骰”恢复默认配置。
- 规则页：基本规则、点数组合、骰子概率、保留/爆骰、获胜条件与牌桌提示。
- 联机入口：顶部“联机演示”切换、房间编号与对手状态，方便后续接入 WebSocket。
- 场景背景：主页使用 `homepage-bg.png` 作为你提供的中世纪骰子插图背景；牌桌场景继续使用 `tavern-bg.svg`。
- 三维骰子层：牌桌中央只使用 Three.js r128 在透明 canvas 上渲染木制骰子本身，`renderer.setClearColor(0x000000, 0)` 保证 2D 牌桌背景直接透出。骰子投射到 `THREE.ShadowMaterial` 地板（`opacity: 0.4`）的实时 PCF 软接触阴影，不再绘制独立木盒模型。
- 物理投掷组件：`dice-physics.js` 使用 Cannon.js 在透明 canvas 上模拟骰子。每位玩家固定六个可复用实体，下一掷只激活未锁定槽位，不会无限堆积 Mesh；锁定骰子在选择后保持可见，下一次投掷开始时才从牌面收起并暂时隐藏，同时移出碰撞，热骰或新回合时由同一实体池重新显示。重力为 `-25`，骰子材质使用摩擦力 `0.5`、弹性系数 `0.3`；四面不可见高墙和地板按照牌桌框尺寸动态测量，内侧边缘与 2D 框内边距重合，碰撞冲量会触发骨质 Web Audio 撞击声和轻微镜头震动。可通过 `window.DicePhysics3D.rollDice(count, targetValues, callback, options)` 投掷，并使用 `onDiceSelected`、`onDragRoll` 接收 3D 交互回调。
- 三维交互：鼠标悬停骰子时显示金色材质微光并切换指针；点击任意 3D 骰子都可通过 `onDiceSelected(diceId, value)` 锁定或解锁，不再要求当前组合先产生分数。零分组合仍可继续投掷并保持 0 分，由玩家自行承担选择结果；拖拽释放会把方向脉冲传给未锁定骰子。牌桌不再渲染 2D 骰子镜像，骰子只存在于透明 Three.js Canvas。
- 投掷反馈：骰盅过渡动画、骰子翻滚动画、可见的对手回合和键位操作提示（E 保留、F 保留并投掷、Q 收集、R 重开、T 规则）。

## 运行

直接打开 `index.html` 即可体验。若希望通过本地 HTTP 服务运行：

```powershell
$python = 'C:\Users\boomhauer\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
Start-Process -WindowStyle Hidden -FilePath $python -ArgumentList '-m','http.server','4173' -WorkingDirectory 'O:\001'
```

然后访问 `http://127.0.0.1:4173/`。

当前项目是前端可玩的离线原型，联机模式使用本地状态机模拟匹配和对手回合，不会建立真实网络连接。Three.js 与 Cannon.js 通过 CDN 加载；若运行环境阻止 CDN，页面会自动隐藏 3D canvas 并保留牌桌 UI，但不会生成 2D 骰子替代层。要做到成品级 1:1 美术还需要替换酒馆背景、角色肖像与骰子材质资源。
